# FoodRescue 🌱

### Save food. Help people.

FoodRescue is a full-stack food donation management system that connects food donors with NGOs and organizations that can distribute surplus food to people in need.

## 📌 Project Overview

FoodRescue helps reduce food waste by providing a platform where users can donate surplus food and NGOs can view and claim available donations.

The application provides separate functionality for:

- Food Donors
- NGOs / Organizations
- Administrators

---

## ✨ Features

### 👤 Food Donor

- Register and login
- Create food donation
- Enter food details and quantity
- Add prepared and expiry dates
- Provide pickup location
- View donation status
- Track submitted donations

### ❤️ NGO / Organization

- Register and login
- View available food donations
- View donation details
- Claim available donations
- Track claimed donations

### 🛡️ Admin

- Admin login
- View registered users
- View donation information
- Manage users
- Monitor the food donation system
